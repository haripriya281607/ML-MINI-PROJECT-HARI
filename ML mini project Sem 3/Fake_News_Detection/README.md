# Fake News Detection Using Machine Learning

## Project Overview
A Machine Learning web application that classifies news statements as FAKE or REAL using NLP techniques.

## Technologies Used
- Python
- Machine Learning
- NLP
- Scikit-learn
- CountVectorizer
- Flask
- HTML and CSS

## Machine Learning Models
- Naive Bayes
- Logistic Regression
- Linear SVM
- Decision Tree
- Random Forest

## Selected Model
Multinomial Naive Bayes with CountVectorizer.

## Installation
Install the required libraries:

pip install -r requirements.txt

## Execution
Run the application:

python app.py

Open your browser and visit:

http://127.0.0.1:5000

## Dataset
LIAR Dataset.

Original labels are grouped into:
- FAKE: pants-fire, false, barely-true
- REAL: half-true, mostly-true, true

## Disclaimer
This application performs automated text classification.
It does not independently verify news facts.
Predictions may be incorrect.
